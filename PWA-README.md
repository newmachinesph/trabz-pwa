# Trabz PWA

A Progressive Web App built with Next.js 16 for the Trabz platform.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Visit: http://localhost:3000

## 📱 PWA Features

✅ **Installable** - Add to home screen on any device
✅ **Offline Support** - Service worker caching
✅ **Fast Loading** - Optimized assets and caching
✅ **Responsive** - Works on mobile, tablet, and desktop
✅ **App Shortcuts** - Quick access to Jobs and Gigs
✅ **Push Notifications** - Ready to implement

## 🛠️ Tech Stack

- **Framework**: Next.js 16.1.6 (App Router)
- **React**: 19.2.3
- **Styling**: Tailwind CSS 4
- **PWA**: @ducanh2912/next-pwa
- **TypeScript**: 5.x

## 📦 PWA Configuration

### Files
- `public/manifest.json` - Web app manifest
- `next.config.ts` - PWA plugin configuration
- Auto-generated service worker in `public/`

### Manifest Details
- **Name**: Trabz - Jobs & Gigs for Filipino Workers
- **Theme Color**: #1E40AF (Trabz Blue)
- **Display Mode**: Standalone
- **Orientation**: Portrait

## 🎨 Icons Needed

Generate and place in `public/`:
- `icon-192x192.png` (192×192px)
- `icon-384x384.png` (384×384px)
- `icon-512x512.png` (512×512px)
- `favicon.ico`

**Generate icons**: https://www.pwabuilder.com/imageGenerator

## 📝 Environment Variables

Create `.env.local`:
```bash
NEXT_PUBLIC_API_URL=https://api.trabz.ph
NEXT_PUBLIC_APP_URL=https://trabz.ph
```

## 🔧 PWA Development

### Service Worker
- Automatically generated by `@ducanh2912/next-pwa`
- Located in `public/sw.js` and `public/workbox-*.js`
- Disabled in development mode

### Testing PWA
1. Build the app: `npm run build`
2. Start production: `npm start`
3. Open Chrome DevTools → Application → Service Workers
4. Test install prompt and offline mode

### Lighthouse Score
Run in Chrome DevTools:
- Performance
- Accessibility
- Best Practices
- SEO
- PWA compliance
